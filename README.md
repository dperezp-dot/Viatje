# 1. Introducción

En este proyecto hemos trabajado con diferentes herramientas de Google.

## 2. Herramientas utilizadas

- **Gmail:** para enviar y recibir correos.
- **Google Maps:** para consultar rutas.
- **Google Sheets:** para organizar el presupuesto.
- **Google Calendar:** para planificar actividades.

## 3. Configuración de Gmail

### 3.1. Etiquetas

Hemos creado etiquetas para organizar los correos.

### 3.2. Filtros

Hemos creado 5 filtros para organizar automáticamente los mensajes.

### 3.3. Respuesta automática

Hemos activado una respuesta automática para los correos recibidos.

## 4. Pruebas de correo

1. Enviar un correo desde la cuenta personal.
2. Recibirlo en la cuenta escolar.
3. Responder desde la cuenta escolar.
4. Comprobar que llega correctamente.
